# NeuroScope — Brain Tumor Classification Website

NeuroScope is a production-style local web interface for the existing Brain Tumor EfficientNetB2 project. A user uploads one MRI image, the Flask API runs the saved `effnetb2_best.keras` checkpoint, and the React interface displays the predicted class, all three probabilities, and Grad-CAM images.

This is an inference application. It does not train a model, download a dataset, compare uploads with training images, or generate placeholder predictions.

## Source-of-truth notebooks

- `B2 (2).ipynb` defines the deployed model, class order, test-image preparation, checkpoint, and Grad-CAM implementation.
- `01_brain_preprocessing.ipynb` documents a contour-cropping research preprocessing experiment.

The B2 notebook's actual test/inference path uses `cv2.imread`, resizes directly to 240 × 240, retains OpenCV BGR channel order, converts the batch to `float32`, and does **not** call contour cropping. The API intentionally preserves that behavior. The separate preprocessing notebook is retained as research reference, but its cropping steps are not silently inserted into deployment inference.

- Frontend: React, Vite, Tailwind CSS, Lucide React, Axios
- Backend: Python, Flask, TensorFlow/Keras, OpenCV, NumPy, flask-cors

## 1. Add the trained checkpoint

Copy the existing checkpoint to:

```text
backend/models/effnetb2_best.keras
```

Do not substitute an untrained or newly generated model. To keep the file elsewhere, edit `backend/.env` and set `MODEL_PATH` to its path.

## 2. Run the backend on Windows

TensorFlow does not currently support Python 3.14. Use a supported 64-bit Python version (Python 3.11 is recommended).

```powershell
cd backend
py -3.11 -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

The API starts at `http://localhost:5000`. If the model is missing or incompatible, startup stops with a specific checkpoint error.

## 3. Run the frontend in a second PowerShell terminal

```powershell
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

Frontend API configuration lives in `frontend/.env`:

```dotenv
VITE_API_URL=http://localhost:5000
```

Backend configuration lives in `backend/.env`:

```dotenv
MODEL_PATH=./models/effnetb2_best.keras
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
FLASK_HOST=127.0.0.1
FLASK_PORT=5000
FLASK_DEBUG=false
```

For a deployed environment, set `CORS_ORIGINS` to the exact frontend origin instead of using `*`.

## API

### `GET /health`

```json
{
  "status": "ok",
  "model": "EfficientNetB2"
}
```

### `POST /predict`

Send `multipart/form-data` with an image in the `file` field. PNG, JPG, and JPEG are accepted up to 10 MB.

The response contains the real checkpoint output:

```json
{
  "prediction": "Glioma",
  "class_index": 0,
  "confidence": 0.98,
  "probabilities": {
    "Glioma": 0.98,
    "Meningioma": 0.01,
    "Pituitary": 0.01
  },
  "gradcam": {
    "original_image": "data:image/png;base64,...",
    "heatmap": "data:image/png;base64,...",
    "overlay": "data:image/png;base64,..."
  }
}
```

The numbers above illustrate the response shape only; the application never hardcodes them.

## Inference and Grad-CAM behavior

1. Validate the filename extension, MIME type, and upload size.
2. Decode bytes using OpenCV.
3. Resize the BGR image to 240 × 240.
4. Convert it to `float32` and add the batch dimension.
5. Run the loaded EfficientNetB2 checkpoint.
6. Preserve class order: Glioma, Meningioma, Pituitary.
7. Select the highest softmax probability.
8. Compute gradients for that predicted class from `top_activation`.
9. Average gradients over batch and spatial dimensions, weight the activation maps, apply ReLU, and normalize.
10. Apply OpenCV's JET colormap and blend 60% MRI with 40% heatmap.

The checkpoint is loaded once when Flask starts, not for every request. Output images are returned as base64 PNG data URLs and are not stored permanently.
